# Ticketz Company Exporter

Ferramenta simples para exportar, por empresa, apenas os dados mínimos necessários para atendimento contractual:

- Messages
- Tickets
- Contacts

A exportação gera um arquivo .tar.gz com três CSVs, filtrados por `companyId`.

## Requisitos

- Instalação automática do Ticketz

## Instalação

Acesse a pasta em que deseja guardar o script e rode:

```bash
nano exportar-ticketz-company.sh
```
